# Pipeline Turnover

Projeto de portfólio voltado à Engenharia de Dados, Análise de Dados e Machine Learning, utilizando uma base de dados de turnover de funcionários.

## Objetivo

Desenvolver um projeto completo para explorar dados de funcionários, construir um pipeline ETL, realizar análises exploratórias e desenvolver um modelo de Machine Learning para estudar a possibilidade de desligamento de funcionários.

## Tecnologias

- Python
- Pandas
- MySQL
- SQL
- Jupyter Notebook
- Scikit-learn

*Outras ferramentas poderão ser adicionadas durante o desenvolvimento.*

## Etapas do Desenvolvimento

### 1. Engenharia de Dados
- Extração dos dados.
- Limpeza e transformação.
- Carregamento dos dados no MySQL.
- Desenvolvimento do pipeline ETL.

### 2. Análise de Dados
- Análise exploratória com Python e Pandas.
- Estatísticas descritivas.
- Identificação de padrões e indicadores de turnover.
- Visualização dos dados.

### 3. Machine Learning
- Preparação dos dados para modelagem.
- Treinamento de modelos de classificação.
- Avaliação dos resultados.
- Estudo da previsão de desligamento de funcionários.
